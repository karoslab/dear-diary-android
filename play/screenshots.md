# Screenshot guidance

Match the iOS App Store set. Phone, dark theme first. Capture a second pass in Light if you have room.

## Device

- Phone, 16:9 or modern Play phone frames (e.g. Pixel 8 / 6.3"+)
- Status bar clean; no developer badges if you can hide them
- Use the in-app **Load sample journal** row on a debug build if you need the screenshot copy (Morning before the rush / Amma made obbattu). Release builds do not show that row.

## Required frames (same order as the iOS listing)

1. **Journal** — streak + entries cards, contribution heatmap, dated list, floating tab bar, “dear diary” serif header, “0 bytes sent” pill. Journal tab gold.
2. **Entry detail** — back, Delete entry, gold timestamp + duration, serif title, audio scrubber, body, “Tap the words to edit”, tags, Export this entry.
3. **Search** — query `amma`, “ran over local entries, 0 bytes sent”, “2 results”, gold underline on Amma, Search tab gold.
4. **Record** — large mic, concentric rings, PRESS TO SPEAK, Record tab gold.
5. **Settings** — Your data, On this device storage bar, Theme (System selected), Speech to text (“Vosk, on this device”). Settings tab gold.
